# Skills
Las `Skills` o habilidades de IA son componentes reutilizables (prompts, instrucciones, plantillas, código) que permiten a la inteligencia artificial ejecutar tareas específicas de forma eficiente, encapsulando el contexto necesario para evitar perder información. Estas capacidades actúan como manuales de trabajo, optimizando procesos, automatizando tareas complejas y mejorando el código generado por la IA. 

Aspectos clave de las skills:
- Funcionalidad: Capacitan a agentes para realizar tareas complejas, como convertir datos de un Excel en un PDF o aplicar estrategias de marketing probadas.
- Implementación: Se pueden crear e instalar en editores de código (como .cursor o .cloud) usando comandos como npx a nivel de proyecto o global.
- Ventaja: Permiten a la IA actuar con la lógica de negocio y el criterio del usuario, mejorando la automatización de flujos creativos y operativos.

Ejemplos:
- Marketing: Empaquetado de estrategias para campañas.
- Programación: Uso de directrices de buenas prácticas para generar código de mayor calidad.
- Administración: Creación de documentos o facturas.
